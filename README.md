# HabitNow – Android Habit Tracker

![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Kotlin](https://img.shields.io/badge/Kotlin-0095D5?style=for-the-badge&logo=kotlin&logoColor=white)

**HabitNow** is a native Android mobile application built with **Kotlin** that helps users create, manage, and track their daily habits. Features include habit streaks, progress tracking, reminders, and a clean, minimal UI designed for daily use.

---

## 📱 Overview

HabitNow is a native Android application designed to help users build positive daily habits through streak tracking, reminders, and progress visualization. Built with Kotlin following modern Android development practices.

## 🛠 Technologies Used

- **Kotlin** – primary programming language
- **Android Studio** – IDE
- **XML Layouts** – UI design
- **SQLite / Room** – local database for offline storage
- **Material Design** – modern UI components
- **MVVM Architecture** – separation of concerns
- **WorkManager** – background reminders & notifications

## ✨ Key Features

- ✅ Daily habit creation and management
- 🔥 Habit streak tracking (current & longest streaks)
- 📊 Progress visualization (charts / completion rates)
- ⏰ Daily reminders and notifications
- 🎨 Clean, minimal Material Design UI
- 💾 Offline support with local database (Room)
- 📅 Habit calendar view (optional, if implemented)
